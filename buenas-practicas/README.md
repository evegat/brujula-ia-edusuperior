# Banco Colaborativo de Buenas Prácticas Docentes con IA
> Brújula IA Educación Superior Chile | Eduardo Vega Toledo (https://evegat.cl)
> Repositorio oficial: https://github.com/evegat/brujula-ia-edusuperior

Este espacio reúne ejercicios de aula, rúbricas de evaluación, metodologías y proyectos prácticos desarrollados por docentes de educación superior en Chile y el mundo.

## Casos Iniciales Documentados
1. [Auditoría de Alucinaciones como Antídoto Crítico](./01-alucinaciones-como-antidoto.md): Uso deliberado de IA para generar textos y contrastar sus fuentes falsas con bibliografía física en 1° año.
2. [Auditoría Inversa de Fórmulas en Excel](./02-auditoria-inversa-excel.md): Desarmar fórmulas matriciales complejas y auditar presupuestos públicos con asistencia de LLMs.
3. [Asistente Virtual para Preparación de Entregas (Caso Cristina)](./03-asistente-formativo-cristina.md): Bot pre-entrenado con rúbricas de evaluación ex-ante y objeciones técnicas de estándar público.
4. [Generación de Scripts de Procesamiento Cuantitativo y Cualitativo](./04-scripts-procesamiento-datos.md): Automatización asistida para limpieza de datos públicos y análisis semántico.

## Cómo proponer una nueva práctica
Si deseas aportar una experiencia implementada en tu carrera o universidad:
1. Haz un **Fork** de este repositorio.
2. Crea un archivo Markdown en esta carpeta siguiendo la plantilla `plantilla-buena-practica.md`.
3. Envía un **Pull Request** o escríbenos directamente a `eduardo@evegat.cl`.
4. Todos los aportes aceptados son publicados en la web oficial con nombre, cargo, universidad y enlace a tu perfil profesional.
